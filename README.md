# Cart Management System

This is a simple console program to manage a shopping cart. It helps you add items, use discount vouchers, and checkout.

## What it can do
- **Find Products**: Look through a list of items you can buy.
- **Manage Cart**: Add items to your cart, change the number of items, or remove them.
- **Use Vouchers**: Type in a code to get a discount on your total price.
- **Save Progress**: The program remembers your cart even if you close and open it again.
- **Cart Threshold**: Each cart can hold up to 10 unique product types.
- **Checkout**: See a summary of your order and the final price in PHP.

## How to use it
1. Open the project in **Visual Studio**.
2. Press the **Start** button or press **F5**.
3. Use the numbers on your keyboard to choose options:
   - `[1]` to add an item.
   - `[2]` to change quantity.
   - `[3]` to remove an item.
   - `[4]` to use a voucher code.
   - `[5]` to checkout.
   - `[0]` to quit.

## Technology used
- **Language**: C#
- **Storage**: InMemory, JSON files, and Database
- **Style**: N-Tier Architecture
